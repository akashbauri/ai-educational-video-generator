# AI Educational Video Generator

An AI-powered educational video generator built with:

- Streamlit
- Qwen3
- Hugging Face Inference
- FLUX
- Edge TTS
- Pillow
- FFmpeg

## Pipeline

Educational Text
        ↓
Qwen
        ↓
Scene JSON
        ↓
AI Images
        ↓
Text-to-Speech
        ↓
Animations
        ↓
Subtitles
        ↓
Background Audio
        ↓
FFmpeg
        ↓
MP4

## Supported Languages

- English
- Hindi
- Bengali

## Supported Education Levels
   From 
- Class 5
- Class 12
- College
- General

## Deployment

The application is designed for Streamlit Community Cloud.

No local Python or FFmpeg installation is required.

## Secrets

Add API credentials through Streamlit Secrets.

Never commit secrets to GitHub.
